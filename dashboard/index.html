SBOM Security Scanner

Checks the dependency list in an uploaded CycloneDX JSON SBOM against the OSV vulnerability database (osv.dev).

  • Only the ecosystem, package name and version of each component are sent to the external OSV API (api.osv.dev).
  • “No known match” means OSV returned no record for that exact package version. It does not prove the package is safe.
  • An incomplete scan is never a clean result.
  • This evaluates the uploaded dependency SBOM only, not the ESP32 firmware binary or the firmware’s overall security.
  • It is independent of AutoQrypt’s release signing and ECU installation checks. The file is not signed, published or sent to the OTA server.
